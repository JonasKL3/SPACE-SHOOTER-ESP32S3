# Controles — v1.0.0

O jogo utiliza o módulo **GamePad** do aplicativo Dabble.

| Controle | Ação |
|---|---|
| UP | Mover nave para cima |
| DOWN | Mover nave para baixo |
| LEFT | Mover nave para a esquerda |
| RIGHT | Mover nave para a direita |
| CROSS | Atirar |
| CIRCLE | Atirar |
| START no menu | Iniciar partida |
| START jogando | Pausar |
| START pausado | Continuar |
| START no Game Over | Reiniciar |
| SELECT no Game Over | Voltar ao menu |

## Bluetooth

Nome configurado na v1.0.0:

```text
ESP32-S3-GAMEPAD
```
